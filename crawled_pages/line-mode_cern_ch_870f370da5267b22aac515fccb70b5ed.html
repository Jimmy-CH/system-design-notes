Webmaster[7]

This is a list of some WWW servers. It does not include all servers, and note that one server machine can serve many databases. See also: background on WWW[8] , and data available by other protocols[9] , data by subject[10] , how to make a new server[11] , test servers[12] . If servers are marker "experimental", you should not expect anything. The top of the list is in reverse chronological order of addition.

NCSA[13]
National Center for Supercomputing Applictions, Urbana Champain, IL, USA. Experimental.
IN2P3[14]
Lyon, France.
KVI[15]
Kernfysisch Versneller Instituut (nuclear physics accelerator institute), Groningen, Netherlands. VMS server.
CWI[16]
Center of Mathematics and Computer Science, Amsterdam. FTP server for hypertext, including Gnu TeXInfo stuff as hypertext.
Cornell[17]
Legal information: US Intellectual Property Statustes on line.
ZEUS[18]
ZEUS experiment at DESY, Hamburg, Germany. [.At least 2 servers]
KEK[19]
KEK, Tsukuba, Japan. Experimental only. [FTP hypertext, http server later)
DESY unix server[20]
Experimental only as yet.
Denmark's Technical Library[21]
The DTB information service includes the library system.
VOICE magazine[22]
The first global online hypertext magazine? Ed. Tom Boutell
SLAC[23]
Stanford Linear Accelerator, California. HEP preprints database and LOTS more... also a unix server[24] .
Technical University of Graz[25]
Information service. Gateway to Hyper-G data.
CCIT Arizona[26]
University of Arizona information
Fermilab[27]
Documentation from online and offline groups. Also at FNAL, very experimental servers in Theory[28] , D0[29] , HEPnet management[30] , ACCESS user consultancy[31] .
ASIS Software Repository[32]
A server for public domain and CERN software for distribution to CERN members only. The documentation is public.
CERN news[33]
Various groups, some more active than others - see the full list[34]
CERN computing documents[35]
A keyword index.
Hebrew University of Jerusalem[36]
Information service - both in hebrew and English, asssumes a VT terminal with hebrew characters. See also their TeX database[37] (July 1992).
Helsinki Technical University[38]
HUT Information tree.
HEPNET[39]
Experimental server (might move!) run by US HEPNet at FNAL.
ICTP[40]
Italian physics institute (experimental server)
FUNET[41] information
Finnish Univerity Research Network.
NIKHEF[42]
The Dutch High-Energy Physics center.
Software Technology[43]
Information from STING organised by Mike Sendall.
VXCRNA help[44]
The VMS help tree on node vxcrna.cern.ch .
WorldWideWeb support[45]
information about W3 itself, CERN entry point, and web overviews.
